# مصادر البيانات القانونية

آخر مراجعة: 2026-11-23. أي مصدر جديد لازم يتراجع بنفس الطريقة قبل ما نجمع منه.

## المصادر اللي اتراجعت

| المصدر | الحالة | التفاصيل |
|---|---|---|
| **منشورات قانونية** (`manshurat.org`، مشروع تابع للجامعة الأمريكية بالقاهرة) | ✅ مسموح بنصوص القوانين بس | `robots.txt` بيسمح بالمحتوى مع `Crawl-delay: 10`. صفحة «عن الموقع» بتقول إن **مقالات الرأي** حقوقها لكتّابها، ومفيهاش نص عن الوثائق الرسمية. بناخد نصوص القوانين فقط، بفاصل 10 ثواني بين الطلبات، ومع ذكر المصدر. |
| **محكمة النقض** (`cc.gov.eg`) | ❌ ممنوع الجمع الآلي للأحكام | `robots.txt` بيمنع `/legal/GetJudgment`، `/legal/GetJudgmentText`، `/legal/get_file` وغيرها. الأحكام لازم تيجي من مصدر تاني أو بإذن. |
| **ويكي مصدر** (`ar.wikisource.org`) | ⚠️ مسموح، بس الجودة متغيرة | نسخة قانون المرافعات هناك ناقصة (169 مادة) وفيها مواد متكررة وملزوقة، **فمااتستوردتش**. |

> حسب علمنا، المادة 141 من قانون الملكية الفكرية 82 لسنة 2002 بتستثني نصوص القوانين والأحكام القضائية من الحماية، **بس ده لسه محتاج مراجعة محامي**. الملخصات والتعليقات اللي بيكتبها محررين محمية في كل الأحوال.

## خطوات الاستيراد (القانون المدني)

```bash
dotnet run --project src/SmartLawyer.Ingestion -- preview-law --file civil.pdf --fix-kaf true
```

```bash
dotnet run --project src/SmartLawyer.Ingestion -- import-law --file civil.pdf --fix-kaf true --title "القانون المدني" --number 131 --year 1948 --valid-from 1949-10-15 --source "منشورات قانونية (manshurat.org/node/72413) — نسخة وزارة المالية وفقاً لأحدث التعديلات"
```

`preview-law` بيعرض عدد المواد والناقص والمكرر قبل الاستيراد، ولازم يتراجع كل مرة.

## مراجعة مطلوبة من محامي

- عينة من المواد المستوردة مقارنة بالنص الرسمي (مقترح: 30 مادة عشوائية).
- إن نسخة وزارة المالية فعلاً بأحدث التعديلات، وتاريخ آخر تعديل.
